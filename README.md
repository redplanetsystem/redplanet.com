## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- API keys: OpenAI, NASA, Alpha Vantage, CoinGecko

### Installation

```bash
# Clone repository
git clone https://github.com/redplanetsite001/redplanet.com.git
cd redplanet.com

# Install dependencies
npm install

# Configure environment
cp .env.example .env.local
# Update .env.local with your API keys

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
